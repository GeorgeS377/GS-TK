# Source Code of the GS TK website (Greek)

### Visit the website at https://www.solomidis.gr (official deployment)

## Forking & deploying

### Prerequisites

- Python
- git (if cloning the latest build)

### Installation Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/GeorgeS377/GS-TK.git
   cd GS-TK
   ```
   You can also find older versions of the website on the official GS
   repository <a href="https://archive.solomidis.gr/GS-TK/">here</a>

2. **Run a local python server**
   ```bash
   python -m http.server
   ```
   Now open your browser at ```localhost:8000``` and the site should be running locally!
